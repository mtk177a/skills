# 日本語参考訳を保守する

## 目的

- 英語正本の意味が変わった場合に、保守対象の日本語参考訳を同期する。
- 英語の変更が日本語の意味に影響しない場合は、内容の変わらない翻訳編集を避ける。
- 英語を公開上および規範上の正本として維持しながら、主な保守者が理解とレビューに再利用できる資料を保つ。

## 保守対象の組み合わせ

- `README.md` → `README.ja.md`
- `AGENTS.md` → `AGENTS-ja.md`
- `CLAUDE.md` → `CLAUDE-ja.md`
- `docs/<name>.md` → `docs/ja/<name>.md`
- 英語正本の場合は `skills/<skill-name>/SKILL.md` → `skills/<skill-name>/SKILL-ja.md`
- `.agents/skills/<tracked-skill>/SKILL.md` → `.agents/skills/<tracked-skill>/SKILL-ja.md`

文書化された日本語正本の Skill には翻訳を作成しません。

## 手順

1. 依頼と現在の diff を確認し、保守対象の組み合わせに含まれる追加または変更された英語正本を特定する。
2. 変更された正本の各節、その周辺の文脈、既存の日本語参考訳がある場合はその対応箇所を読む。
3. 正本の変更が日本語の読者に必要な意味へ影響するか判断する。\
   要件、対象範囲、例外、権限、禁止事項、安全条件、手順、検証、リンク、文書構造は、正しい利用に影響する場合に意味を持つものとして扱う。
4. 意味が変わる場合は、同じ変更内で対応する日本語参考訳を作成または更新する。\
   正本文書の関係と意図を保てる最小のまとまりを編集する。
5. 意味が変わらない場合は日本語ファイルを変更せず、その判断理由を記録する。
6. 更新後の組み合わせについて、意味の整合、リポジトリ内の用語、翻訳通知、Markdown 構造、意図しない変更を確認する。

`must`、`should`、`may` などの規範強度に加え、除外、承認境界、失敗条件、不確実性を維持します。\
正本の変更に対応する更新が必要な場合を除き、frontmatter の項目、見出し、リンク、コード、コマンド、識別子、表、整形上の制約を維持します。

リポジトリの日本語参考訳ですでに使われている用語を優先します。\
正本にない説明、方針、例、主張を追加しません。\
正本の意味または既存の訳語に重要な曖昧さがある場合は、推測せず、対象の組み合わせと曖昧な点を報告します。\
独立した組み合わせの作業は可能な範囲で続けます。

## 報告内容

次の内容を報告します。

- 確認したすべての保守対象の組み合わせ
- 各日本語参考訳を作成、更新、または無変更とした結果
- 日本語参考訳を変更しなかった場合の意味上の理由
- 実行した検証とその結果
- 解消していない曖昧さまたは未確認の組み合わせ

## 境界

- 翻訳保守の一部として英語正本を編集しない。
- 日本語正本の Skill、Issue や pull request の作成、保守対象外の一般翻訳には使用しない。
- 外部翻訳サービスを使用せず、依存を追加しない。
- ユーザーの依頼や適用される指示で許可されていない限り、コミット、プッシュ、課題管理ツールへの投稿、使用するモデルの変更、サブエージェントの起動を行わない。
- この Skill は `write-natural-japanese` を必須としない。\
  両方の Skill を使用する場合は、この Skill が正本への忠実さと対象範囲を管理し、`write-natural-japanese` がその範囲内で日本語の表現を整える。
