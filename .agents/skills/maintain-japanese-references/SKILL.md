# 日本語参考訳を保守する

英語版の変更によって、日本語参考訳が伝える内容が変わった場合に、対応する訳文を更新する。\
英語版の変更が訳文の伝える内容に影響しない場合は、日本語のファイルはそのまま保つ。\
要件を判断する基準は英語版であり、日本語参考訳は、保守者が内容を理解して確かめるためのものである。

## 手順

1. **`write-natural-japanese` を読む**

   最初に、このリポジトリの `skills/write-natural-japanese/SKILL.md` を読む。\
   日本語のファイルを変更しないと判断する場合も、読む。\
   英語から日本語へ訳す場合は、訳文を編集する前に、`skills/write-natural-japanese/references/wording-decisions.md` も最後まで読む。\
   必要なファイルがない場合や読めない場合は、この Skill による判断と編集を止め、使えなかったファイルを報告する。\
   個人の環境にある同じ名前の Skill は、代わりに使わない。

2. **対応する参考訳を特定する**

   英語版の `docs/maintainers/localization.md` の対応表を読む。\
   依頼と現在の差分から、追加または変更された英語版と、それに対応する日本語参考訳を特定する。\
   日本語参考訳を編集する前に、表で対応するファイルを確定する。\
   表から対応を一つに特定できない場合は、その組の判断と編集を止め、未決定の対応として報告する。\
   要件を日本語の `SKILL.md` で定めている Skill は、日本語の `SKILL.md` だけを持ち、この表の対象外である。

3. **変更箇所を読む**

   英語版の変更箇所とその前後を読み、既存の日本語参考訳があれば、対応する箇所も読む。

4. **伝える内容が変わるかを判断する**

   英語版の変更によって、日本語の読者に伝える内容が変わるかを判断する。\
   要件、対象の範囲、例外、許可、禁止、安全上の条件、手順、検証方法、リンク、文書の構造のうち、正しい利用に影響するものが変わった場合は、訳文に反映する。\
   伝える内容が変わらない場合は、日本語のファイルはそのまま保ち、その理由を記録する。\
   組ごとに、反映するか、そのまま保つかが決まれば完了とする。

5. **訳文を作成または更新する**

   伝える内容が変わる場合は、同じ変更の中で、対応する日本語参考訳を作成または更新する。\
   英語版の記述どうしの関係と意図を保ち、必要な箇所をまとまりとして編集する。\
   訳文は、[同じ考え方を日本語に当てはめる](../../../docs/ja/maintainers/authoring.md#同じ考え方を日本語に当てはめる) の規則に従う。\
   次の点を守る。

   - 原文の `must`、`should`、`may` が表す、義務、推奨、許可の違いを保つ。
   - 除外、承認の条件、失敗の条件、不確実性を残す。
   - 英語版の変更に対応する場合を除き、frontmatter の項目、見出し、リンク、コード、コマンド、識別子、表、整形上の制約を保つ。
   - リポジトリの日本語参考訳で定着している用語を使う。\
     このリポジトリに固有の概念や、別々のものを指し得る語は、`docs/maintainers/glossary.md` で、指すものに応じた語を確かめる。
   - 訳文に書くのは、原文にある説明、方針、例、主張だけにする。

6. **曖昧な点と英語版の問題を報告する**

   原文の意味や既存の訳語に、訳文が変わるほどの曖昧さがある場合は、推測せずに、対象のファイルと曖昧な点を報告する。\
   英語版の構造や言い回しのせいで、意味を保ったまま読みやすい日本語にできない箇所は、英語版の問題として、対象の箇所と理由を報告する。\
   英語版の修正は、別の依頼として扱う。\
   ほかの組は、独立して判断できる範囲で作業を続ける。

7. **読み直す**

   更新した日本語参考訳を、最初から読み直す。\
   英語版との意味の一致、自然な表現、既存の用語、英語版を基準とする旨の注記、Markdown の構造、意図しない変更を確かめる。

この Skill は、変更の対象、原文との意味の一致、編集の範囲を判断する。\
`write-natural-japanese` は、その範囲の中で、日本語の語と文の組み立てを確かめる。\
読みやすさのための変更は、原文の要件や適用の条件を保つ範囲で行う。

## 報告

- 確かめた英語版と日本語参考訳の組
- 各日本語参考訳を、作成した、更新した、そのまま保ったのいずれか
- そのまま保った場合は、訳文の伝える内容が変わらない理由
- 実行した確認と、その結果
- 解消していない曖昧さと、確かめていない組
- 英語版で直す必要がある箇所と、その理由

## 権限

- 翻訳は、外部の翻訳サービスや新しい依存関係を使わず、エージェント自身が行う。
- コミット、プッシュ、Issue の管理ツールへの投稿、使うモデルの変更、サブエージェントの起動は、ユーザーの依頼か、適用される指示が許可する場合だけ行う。
