# 実行条件とクライアントごとの違い

このガイドは、クライアントで Skill を使う人に向けたものである。\
Skill を実行するためにエージェントに必要なもの、それ以上の条件がある Skill、クライアントごとの Skill の呼び出し方とツールの制御の違いを説明する。\
クライアントを選ぶとき、また、ファイルの書き込み、Web の利用、サブエージェントの起動を伴う作業を始める前に読む。

## すべての Skill に必要なこと

1. **クライアントが、各 Skill のディレクトリにあるファイルを読める**
   - `SKILL.md` だけでなく、同梱資料を読む Skill がある。\
     `define-referents` と `write-natural-japanese` は、作業を始める前に同梱の参照資料を全文読む。
   - Skill にはスクリプトが含まれていないので、Skill のためにクライアントがコードを実行したり、Python ライブラリを追加したりする必要はない。
2. **作業の対象に、エージェントがアクセスできる**
   - リポジトリに対する作業では、ファイルと差分にアクセスできる必要がある。\
     ログ、文書、外部サービスに対する作業では、それらにアクセスできる必要がある。
   - エージェントが確認できなかったものは、回答が完結しているように見えても、確認されていない。
3. **作業に伴う操作が許可されている**
   - ファイルの書き込み、外部サービスへの操作、サブエージェントの起動には、2 つの許可が必要である。\
     クライアントの許可設定で許されていることと、依頼で許可していることである。
   - Skill をインストールしたり呼び出したりしても、どちらの許可にもならない。\
     どの操作を依頼なしに行わないかは、各 Skill に書かれている。

## 追加の条件がある Skill

上の条件に加えて条件があるのは、次の 3 つの Skill だけである。

### Web へのアクセス

`research-web-safely` は、Web を検索し、出典として示す情報源を読む。\
クライアントが Web にアクセスできない場合、この Skill は記憶から答えず、該当する主張を未検証として報告する。

### 独立したサブエージェント

`revise-docs-fresh-eyes` は、文書を書いたときの会話を引き継がないサブエージェントに、文書を改稿させる。\
そのようなサブエージェントを起動できる Codex と Claude Code でだけ動く。\
サブエージェントを使えない場合や許可されていない場合、この Skill は改稿を行わなかったことを報告して止まる。

### 一緒にインストールする Skill

`cognitive-rhythm-writing` は作業を始める前に `japanese-tech-writing` を読むので、2 つの Skill を一緒にインストールする。\
ほかに、別の Skill を必要とする Skill はない。\
[次に使う Skill を選ぶ](workflows.md) に書いたつながりは、次に使う Skill の案内であり、依存関係ではない。

## クライアントごとの違い

### Skill の呼び出し方

クライアントは、依頼が Skill の説明に合うと、その Skill を自分で選ぶことがある。\
特定の Skill を確実に使うには、明示的に呼び出す。

| クライアント | Skill を明示的に呼び出す方法 |
| --- | --- |
| ChatGPT（Chat、Work、dots） | [ChatGPT と Codex で使う](installation.md#chatgpt-と-codex-で使う) のように、Plugin を選び、依頼文で Skill を指定する。 |
| Codex の CLI と IDE 拡張機能 | `/skills` を実行するか、`$` に続けて Skill の名前を入力する。 |
| Claude Code | メッセージの先頭に、`/` に続けて Skill の名前を書く。 |
| Cursor | チャットで、`/` に続けて Skill の名前を入力する。 |

GitHub Copilot や Gemini CLI などのその他のクライアントでは、そのクライアントの公式資料を確認する。

### ツールと操作の制御

エージェントが使えるツールと、承認が必要な操作は、クライアントごとに独自の設定で制御される。\
Codex ではサンドボックスと承認の設定、Claude Code では許可設定である。

ファイルの書き込みや外部サービスへのアクセスを伴う作業の前に、これらの設定を確認する。\
Skill の指示によって、クライアントが許可する範囲が変わることはない。

### 公式資料

クライアントの動作は、バージョンによって変わることがある。\
作業に影響する点は、使っているクライアントの最新の資料で確認する。
