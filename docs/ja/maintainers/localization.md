# 言語と日本語参考訳

このガイドは、保守者と、保守者の代わりに作業するエージェントに向けたものである。\
内容の種類ごとに使う言語、日本語参考訳を持つファイル、参考訳を更新する条件を定める。

## 言語を選ぶ

- **Skill の本文**: 原則として英語で書く。\
  日本語の例外は [Skill のファイル](#skill-のファイル) を参照する。
- **コミットの要約、Issue と PR のタイトル、`Summary` の節**: 検索しやすく、一覧で見分けやすいように、英語で書く。\
  コミットの要約は短く具体的に書き、形式は [変更の進め方](../../../CONTRIBUTING-ja.md) に従う。
- **Issue と PR のその他の節、コメント**: 原則として日本語で書く。\
  すべてを日英の両方で書く必要はない。

## Skill のファイル

各 Skill の基準となるファイルは `SKILL.md` の一つだけで、原則として英語で書く。\
固有名詞、設定キー、定着した技術用語は、元の表記のまま使う。\
一つのクライアントに固有の用語は、その Skill に不可欠な場合だけ使う。

日本語の執筆や推敲を主な目的とする Skill では、日本語の `SKILL.md` を基準にしてもよい。\
その Skill には `SKILL-ja.md` を置かない。\
例外とした Skill と、それを導入した場所を、次の表に記録する。

| Skill | 導入した場所 |
| --- | --- |
| `skills/write-natural-japanese/` | [#43](https://github.com/mtk177a/skills/pull/43) |
| `.agents/skills/maintain-japanese-references/` | [#42](https://github.com/mtk177a/skills/pull/42)。例外は [#77](https://github.com/mtk177a/skills/issues/77) に記録 |

2 つの上流 Gist のミラーも日本語で書かれている。\
これらは、この例外ではなく、[上流 Gist のミラー](authoring.md#上流-gist-のミラー) のコピー規則に従う。

## 日本語参考訳

日本語参考訳は、保守者が同じ内容を何度も翻訳せずにリポジトリを理解し、レビューできるようにするためのものである。\
要件を定めるのは英語版である。\
参考訳は英語版の意味を保ち、要件を追加しない。

### ファイルの参考訳を探す

次の表は、基準となるファイルと、その日本語参考訳の対応を示す。\
基準となるファイルを変更したときは、この表で対応する参考訳を探す。

| 基準となるファイル | 基準となる言語 | 日本語参考訳 |
| --- | --- | --- |
| `skills/<skill-name>/SKILL.md` | 英語。記録した例外では日本語 | `skills/<skill-name>/SKILL-ja.md`（英語が基準の場合のみ） |
| `README.md` | 英語 | `README.ja.md` |
| `CONTRIBUTING.md` | 英語 | `CONTRIBUTING-ja.md` |
| `AGENTS.md` | 英語 | `AGENTS-ja.md` |
| `docs/<audience>/*.md` | 英語 | `docs/ja/<audience>/*.md` |
| `.agents/skills/<tracked-skill>/SKILL.md` | 英語。記録した例外では日本語 | `.agents/skills/<tracked-skill>/SKILL-ja.md`（英語が基準の場合のみ） |

`<audience>` は `users` または `maintainers` である。

次のファイルには、日本語参考訳を置かない。

- 各 Skill の同梱資料（`references/*.md` など）
- `THIRD_PARTY_NOTICES.md` と各 `UPSTREAM.md`
- `.github/` にあるファイル

新しく追加した基準となるファイルが、表のどの行にも、上の一覧にも当てはまらない場合は、表に行を追加する。\
表から参考訳を一つに特定できないファイルについては、未決定の組み合わせとして報告する。\
参考訳を作るのは、組み合わせが決まり、ここに記録された後にする。

### 注記を置く

すべての日本語参考訳の先頭に、次の注記を置く。\
フロントマターがある場合は、その直後に置く。\
ファイル名と相対リンクは、対応する英語版に合わせる。

```markdown
> この文書は [英語版 SKILL.md](SKILL.md) の日本語参考訳です。\
> 内容が異なる場合は英語版を優先してください。
```

## 英語版の変更に合わせて参考訳を更新する

英語版を追加または変更したときは、同じ変更の中で対応する日本語参考訳を確認する。

| 英語版の変更 | 参考訳への対応 |
| --- | --- |
| 意味や正しい使い方に影響する。 | 同じ変更の中で参考訳を更新または作成する。 |
| 日本語で伝える内容に影響しない。 | 参考訳は変更せず、その理由を PR の検証欄かフォローアップ欄に記録する。 |

ここでいう意味には、要件、範囲、例外、許可、禁止事項、安全上の条件、手順、検証方法、リンクなど、正しく使うために必要な情報が含まれる。

この確認と更新には、リポジトリ内の運用 Skill である `maintain-japanese-references` を使う。\
このリポジトリ固有の概念や、別々のものを指し得る語を訳すときは、[用語集](glossary.md) を確認する。
