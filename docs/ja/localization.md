# 言語と日本語参考訳の方針

Skill と文書に使う言語、英語版と日本語参考訳の対応、更新方法を定める。

## Skill の内容を定めるファイルの言語

各 Skill では、`SKILL.md` を唯一の基準となるファイルとする。\
原則として英語で書く。

日本語の執筆・推敲そのものを目的とする Skill では、日本語の `SKILL.md` を基準にできる。\
その場合は例外と出典を文書化し、重複する `SKILL-ja.md` は追加しない。

## 日本語参考訳

日本語参考訳は、保守者が同じ内容を何度も翻訳せずに理解・レビューできるように維持する。\
要件は英語版で定め、参考訳には意味を変えたり要件を追加したりしない。

すべての日本語参考訳は、先頭に次の注記を置く（フロントマターがある場合はその直後）。\
ファイル名と相対リンクは、対応する英語版に合わせる。

```markdown
> この文書は [英語版 SKILL.md](SKILL.md) の日本語参考訳です。\
> 内容が異なる場合は英語版を優先してください。
```

次の表で、保守する英語版と日本語参考訳の組み合わせを定める。\
変更された英語版に対応する参考訳をこの表で特定し、既存の行やパターンに該当しない組を追加するときは、ここに記録する。

| ファイル | 内容の基準となる版 | 参考訳 |
|----------|------|----|
| `skills/<skill-name>/SKILL.md` | 原則は英語。文書化した日本語の執筆・推敲用 Skill は日本語 | 英語版を基準とする場合は `skills/<skill-name>/SKILL-ja.md` |
| `README.md` | 英語 | `README.ja.md` |
| `CONTRIBUTING.md` | 英語 | `CONTRIBUTING-ja.md` |
| `AGENTS.md` | 英語 | `AGENTS-ja.md` |
| `CLAUDE.md` | 英語 | `CLAUDE-ja.md` |
| `docs/*.md` | 英語 | `docs/ja/*.md` |
| `.agents/skills/<tracked-skill>/SKILL.md` | 原則は英語。文書化した日本語の執筆・推敲用 Skill は日本語 | 英語版を基準とする場合は `.agents/skills/<tracked-skill>/SKILL-ja.md` |

表から対応するファイルを一つに特定できない場合は、ファイル名を推測したり参考訳を作成したりせず、未決定の組を報告する。\
対応を決めたら、この表に記録する。

## 訳の同期維持

内容の基準となる英語版を追加または変更した場合は、同じ変更内で対応する日本語参考訳を確認する。

英語版の変更が意味に影響する場合は、日本語参考訳を更新または作成する。\
意味には、要件、対象範囲、例外、権限、禁止事項、安全条件、手順、検証、リンクなど、文書を正しく利用するために必要な情報を含む。

英語版の変更が日本語の意味に影響しない場合は、内容の変わらない編集を加えず、日本語参考訳をそのままにする。\
その判断理由は PR の `検証` または `リスク / フォローアップ` に記録し、レビュー時に確認できるようにする。

この確認と同期判断には、リポジトリ内の運用 Skill の `maintain-japanese-references` を使用する。\
日本語の `SKILL.md` を基準とする Skill はこの手順の対象外であり、重複する `SKILL-ja.md` を作成しない。

## Skill 本文の言語

- Skill 本文: 原則は英語。\
  文書化した日本語の執筆・推敲用 Skill は日本語
- 固有名詞、設定キー、技術用語: 元の形式のままにする
- エージェント固有の専門用語は、その Skill の核心的な価値でない限り避ける

## コミットメッセージの言語

コミットメッセージの要約は英語で短く具体的に書く。

コミットメッセージと PR タイトルの詳しい規約については [変更の進め方](../../CONTRIBUTING-ja.md) を参照する。

## Issue と PR の言語

公開リポジトリでの検索性と一覧性を保つため、Issue と PR のタイトルおよび `Summary` は英語で書く。

それ以外の本文とコメントは日本語を既定とする。\
本文全体を英語版と日本語版に重複させる必要はない。
