# ローカライゼーション

このドキュメントは、このリポジトリの Skill とドキュメントの言語方針を説明します。

## 正本の言語

`SKILL.md` は各 Skill の唯一の正本ソースです。英語を原則とします。
日本語の執筆・推敲そのものを目的とする Skill は、日本語の `SKILL.md` を正本にできます。その場合は例外と出典を文書化し、重複する `SKILL-ja.md` は追加しません。

必須 frontmatter:

```yaml
---
name: skill-name
description: What the Skill does and when it should be used.
license: MIT
---
```

## 日本語参考訳

日本語参考訳は、主な保守者が繰り返し読む技術文書を理解し、レビューするための再利用可能なキャッシュとして保守します。\
閲覧や編集のたびに同じ内容を翻訳し直す必要を減らすことが目的です。

公開上および規範上の正本は英語版です。\
日本語参考訳は要件を定義せず、正本にない意味を追加してはいけません。

`SKILL.md` が英語正本の場合、`SKILL-ja.md` は非正本の日本語訳として同じ場所に置きます:

```
skills/<skill-name>/
├── SKILL.md       # 英語正本
└── SKILL-ja.md   # 日本語参考訳
```

`SKILL-ja.md` の先頭には、英語版が正本であることを示す通知を記載する必要があります:

```markdown
> **注記:** 英語版 (`SKILL.md`) が正本です。
> このファイルは参考訳です。
```

同じ方針が他の訳ファイルにも適用されます:

| ファイル | 正本 | 訳 |
|----------|------|----|
| `SKILL.md` | 原則は英語。文書化した日本語の執筆・推敲用 Skill は日本語 | 英語正本の場合は `SKILL-ja.md` |
| `README.md` | 英語 | `README.ja.md` |
| `AGENTS.md` | 英語 | `AGENTS-ja.md` |
| `CLAUDE.md` | 英語 | `CLAUDE-ja.md` |
| `docs/*.md` | 英語 | `docs/ja/*.md` |

## 訳の同期維持

保守対象の英語正本を追加または変更した場合は、同じ変更内で対応する日本語参考訳を確認します。

正本の変更が意味に影響する場合は、日本語参考訳を更新または作成します。\
意味には、要件、対象範囲、例外、権限、禁止事項、安全条件、手順、検証、リンクなど、文書を正しく利用するために必要な情報を含みます。

正本の変更が日本語の意味に影響しない場合は、内容の変わらない編集を加えず、日本語参考訳をそのままにします。\
その判断理由は pull request の `検証` または `リスク / フォローアップ` に記録し、レビュー時に確認できるようにします。

この確認と同期判断には、repo-local Skill の `maintain-japanese-references` を使用します。\
日本語正本の Skill はこの手順の対象外であり、重複する `SKILL-ja.md` を作成しません。

## Skill 本文の言語

- Skill 本文: 原則は英語。文書化した日本語の執筆・推敲用 Skill は日本語
- 固有名詞、設定キー、技術用語: 元の形式のままにする
- エージェント固有の専門用語は、その Skill の核心的な価値でない限り避ける

## コミットメッセージの言語

コミットメッセージのサマリーは英語で短く具体的に書きます。

完全なコミットメッセージ規約については `AGENTS.md` を参照してください。

## Issue と pull request の言語

公開リポジトリでの検索性と一覧性を保つため、Issue と pull request のタイトルおよび `Summary` は英語で書きます。

それ以外の本文とコメントは日本語を既定とします。本文全体を英語版と日本語版に重複させる必要はありません。
