# write-natural-japanese の評価

## 評価方法

文章の仕上がりを試すケースは `evals.json`、Skill の選択を試すケースは `triggers.json` に置く。`../../../docs/evaluation.md` に従い、変更した判断に必要なケースだけを選び、`scripts/run_skill_evaluation.py plan` でモデル呼び出し数を確かめてから実行する。採点条件は実行時のエージェントへ渡さない。

意味・条件・確度・発話意図、根拠、開示、変更範囲、正確な文字列を先に判定し、自然さで失敗を相殺しない。出力品質と Skill の選択・参照資料の読込みを別々に確認する。prompt、出力、トレース、一時 fixture はリポジトリ外に置く。

## 直近に実行したモデル評価

評価対象は `32ce1c1` の `SKILL.md` と `references/wording-decisions.md`。Codex CLI 0.155.1、gpt-6-luna、max reasoning、read-only fixture、既存 keyring 認証、一時 HOME で個人側の同名 Skill を隔離した。H のみを計画し、1 回実行した。static check、Skill の表示確認、環境の隔離はいずれも通過した。

H は原文の要件、条件、識別子、製品名を保持した。本番環境へのデプロイ前に必要なレビュー担当者の承認を明記し、便宜上の呼び名を「最後の品質確認」と表した。製品機能 DeployGuard Quality Gate の名前は保持した。トレースには参照資料 6,032 文字の全文読込みが記録され、選定した条件を満たした。
