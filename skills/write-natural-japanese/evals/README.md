# write-natural-japanese の評価

この Skill は日本語の文章作成・編集を受け持つため、`SKILL.md` を日本語の正本とする。Skill と参照資料は本リポジトリで作成した MIT ライセンスの内容であり、外部 Skill を翻案していない。

## 目的と方法

変更した判断について、意味・条件・確度・発話意図、根拠、開示、変更範囲、正確な文字列を先に判定する。自然さの改善でこれらの失敗を相殺しない。出力品質と、Skill の選択・参照資料の読込みは別の証拠として確認する。

動作定義は `evals.json`、呼出し定義は `triggers.json` にある。いずれも `../../../docs/evaluation.md` の実行形式を使い、採点条件は実行時のエージェントへ渡さない。変更した責務に必要な例だけを選び、`scripts/run_skill_evaluation.py plan` で呼出し数を見てから実行する。結果は選定した条件に沿って人が判定する。

生の prompt、出力、トレース、一時 fixture はリポジトリ外に置き、`results.json` や `report.json` は今回 commit しない。過去の詳細な実行経緯は Git 履歴と [PR #136](https://github.com/mtk177a/skills/pull/136) に残る。
